Find the smallest useful check.

ProbeStep is an open-source skill for Codex and Claude Code. When a task stalls or a decision depends on an untested assumption, it asks what evidence would change your next action.

Try the preview View the GitHub repository

The experiment notebook

Why ProbeStep exists

Repeated checks on difficult tasks led to a small rule. The next check earns its place only when a plausible result could change the decision.

What the tests found

The earlier Codex pilot tied the baseline on all six cases. Later fixture tests checked completion, evidence handoffs, and when to pause.

See how one check with a mock provider shaped conversation history in the chatbot workflow guide.
